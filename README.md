# persebaran_sekolah_negeri_pringsewu
Peta interaktif persebaran SMA Negeri di Kabupaten Pringsewu berbasis Leaflet.js. Project ini menampilkan titik lokasi sekolah, batas wilayah administrasi, dan informasi sekolah melalui popup. Dibuat untuk memudahkan visualisasi data pendidikan secara sederhana, informatif, dan mudah diakses.
